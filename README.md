# RobloxCleanPro

Skill Claude pour Roblox Studio : il analyse ton jeu et améliore son UI/UX (boutons, menus, inventaire, animations, responsive, design system) sans casser le gameplay.

**Créé par Sherlogs.**

## Installation

### Dans Claude (claude.ai / application)
1. Télécharge ce dépôt (**Code → Download ZIP**) et décompresse-le.
2. Compresse le dossier `robloxcleanpro/` en `robloxcleanpro.zip`.
3. Dans Claude : **Paramètres → Capacités (Skills) → Téléverser un skill**, choisis le zip.
4. Active le skill.
5. Teste : `RobloxCleanPro polish mon jeu`.

### Dans Claude Code
```bash
git clone https://github.com/belekcompte-design/cleanrobloxpro
cp -r cleanrobloxpro/robloxcleanpro ~/.claude/skills/
```
Relance Claude Code puis écris `RobloxCleanPro polish mon jeu`.

## Utilisation
- `RobloxCleanPro améliore toutes les UI`
- `RobloxCleanPro améliore les boutons`
- `RobloxCleanPro rends mon inventaire professionnel`
- `RobloxCleanPro optimise les UI mobile`
- `RobloxCleanPro refais le design du jeu`
- `RobloxCleanPro polish mon jeu`

Pour qu'il modifie directement ton jeu, ouvre-le dans Roblox Studio avec l'application de bureau Claude liée. Fais une sauvegarde avant une grosse refonte.
